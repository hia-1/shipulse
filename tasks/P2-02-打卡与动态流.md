- **动态流页**（页面清单第 7 页）：单信息流，热门/最新排序 + 打卡/书评/书单类型筛选（「关注」Tab 二期预留）

## 实现说明
- 后端 `PostModule`：`posts` 表实体 + PostController + PostService + FeedService。
  - 阅读打卡 `POST /posts/checkin`：校验书籍上架；每日一次防重复（含软删除防刷）；从当日该书的已完成场次汇总时长（`read_minutes`，缺省可手动补充），无今日阅读时长则拦截；机审通过即发布。
  - 图文动态 `POST /posts`：content/images/location，复用 P1-08 `ModerationService` 机审状态机（approve→发布 / pending→挂起 / reject→驳回）。
  - `GET /posts/today` 今日打卡状态与阅读时长（打卡按钮态）；`GET /posts/my` 我的动态（含审核态）；`GET /posts/:id` 详情（登录带点赞态）；`POST /posts/:id/like` 点赞；`DELETE /posts/:id` 软删除。
  - 动态流 `GET /feed`：聚合 打卡/图文动态 + 书评 + 书单，热门/最新排序 + 类型筛选（全部/打卡/图文/书评/书单）。热门=点赞+评论（书单=收藏数），各源取 offset+pageSize 按全局指标排序后合并切片，保证分页序列正确；书单「关注 Tab」按二期预留。
- 前端：`api/feed.ts` API 层 + `FeedView.vue` 动态流页（排序切换、类型 Tab、发布图文弹窗、打卡弹窗、点赞交互、加载更多）；首页导航新增「动态」「书单」入口；路由 `/feed` 注册。
