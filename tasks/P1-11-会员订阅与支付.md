# P1-11 会员订阅与支付

- **编号**：P1-11
- **任务名称**：会员订阅与支付
- **阶段**：P1 核心闭环
- **状态**：已完成

## 前置要求
- 材料：《功能需求.md》② 会员订阅、④ 流程7（会员订阅）、⑦ 会员交易域四表、⑧ 微信虚拟支付合规
- 依赖子任务：P0-05（账号体系）

## 任务内容
实现核心闭环的商业化一环：
- **会员中心页**（页面清单第 12 页）：月卡/年卡套餐卡片、权益对比表、FAQ、购买按钮 + 场景化弹窗
- **四表模型**：membership_plans（套餐）、member_subscriptions（订阅）、orders（订单）、payment_records（支付流水）
- **微信支付**：下单 → 支付 → 回调 → 即时开通（沙箱先行，预留正式商户接入）
- **自动续费**：续费签约、到期自动扣款、扣款失败处理（需求明写支持自动续费）
- **试用与兑换码**：新用户试用（防刷风控）、兑换码核销（一次性）
- **权益门控**：深度时脉报告 + 数据导出等会员权益按订阅状态放行/拦截
- **到期提醒**：到期前 7/3/1 天提醒任务；到期保留数据、续费恢复权益

## 结果
用户可选套餐、支付、即时开通会员，权益即时生效，商业化闭环成立。

## 产物
- 会员中心页（`/membership`：会员状态卡、月卡/年卡套餐卡、权益对比表、FAQ、购买弹窗（含自动续费开关）、试用卡、兑换码输入）
- 会员模块后端接口：`GET /membership/plans`、`POST /membership/orders`、`POST /membership/pay/sandbox`（沙箱支付回调，正式替换微信异步通知）、`GET /membership/my`、`GET /membership/orders`、`POST /membership/trial`、`POST /membership/redeem`
- 实体：membership_plans / orders / member_subscriptions / payment_records / redeem_codes / notifications（提醒落库）
- 定时任务（`setInterval` 实现，免装 @nestjs/schedule）：自动续费（到期扣款续期）、到期 7/3/1 天提醒 + 到期回收
- 权益门控：`GET /reading/pulse/export` 非会员拦截（403）
- 兑换码种子：`MEMBER730`（30 天，一次性）
