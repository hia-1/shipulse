# P0-02 设计系统与基础组件库

- **编号**：P0-02
- **任务名称**：设计系统与基础组件库
- **阶段**：P0 地基与数据
- **状态**：已完成

## 前置要求
- 材料：DESIGN.md（完整 Design Token 定义）、《功能需求.md》⑤ 界面风格
- 依赖子任务：P0-01（web-user 工程已就绪）

## 任务内容
将 DESIGN.md 的色板 / 字体 / 间距 / 圆角 / 投影转成 Tailwind 主题配置，并沉淀基础组件：
- **Token 落地**：色板（paper/ink/pine/gold 体系 + 语义色）、字体层级（display/headline/title/body/label）、间距（space-2xs~4xl）、圆角（sm~full）、投影（Level 0~3）
- **双主题**：浅色 + 深色，跟随系统切换，深色 Token 映射见 DESIGN.md
- **基础组件**：
  - 按钮（主 / 次幽灵 / 文字链接）
  - Chip 与筛选器（默认 / 选中态）
  - 输入框与文本域（默认 / 聚焦光晕）
  - 内容卡片（Level 1 表面）
  - 模态面板（Level 3 磨砂背景）
  - 空状态
  - 书封卡（3:4 宽高比 + 书脊投影）

## 结果
所有后续页面开发直接引用统一 Token 与组件，视觉与需求⑤一致，无需重复定义样式。

## 产物
- Tailwind 主题配置文件（含 Design Token）
- Token 说明文档
- `components/base/` 基础组件集
- 组件演示页（展示全部组件各状态）
