## 实现说明
- **反馈接口**：`POST /feedback`（登录用户提交，5 次/分限流；内容 5–1000 字、类型 suggestion/bug/other、联系方式选填，配图 URL 走 http/https 白名单校验）、`GET /feedback/mine`（我的反馈分页，返回状态与官方回复）。
- **反馈页面**：类型选择 + 内容（含字数计数）+ 联系方式；提交后刷新「我的反馈」列表，展示状态（待处理/处理中/已回复/已关闭）与官方回复。
- **帮助中心**：5 大分类 FAQ（账号登录 / 阅读计时 / 书评社区 / 会员支付 / 隐私安全）折叠展开 + 关键词实时过滤 + 反馈引导。
- **关于我们**：品牌定位、三项价值主张（记录/看见/同频）、六大核心功能、联系渠道。
- **协议页合规**：隐私政策新增「最小必要」采集声明与注销说明（数据删除/匿名化、不可撤销）；协议页底部与首页页脚互通入口。
