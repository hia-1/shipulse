## API 一览（消费 P1-01）
- `GET /api/library/categories` — 分类树（含 bookCount）
- `GET /api/library/tags` — 标签列表
- `GET /api/library/books` — 列表（page/pageSize/categoryId/tagId/sort）

## P1-02 配套后端增强
- P1-01 的书单按 `category_id` 精确过滤，一级分类（如「文学小说」id=1）下无直接挂在父分类的书，导致一级分类切换恒为空。
- `books.service.ts::list` 新增「一级分类展开」：选中分类时按 `自身 + 全部直接子分类` 的 id 集合过滤（`expandCategory` 辅助方法），一级分类切换结果正确。
- 一次性数据回填 `scripts/backfill-counts.js`：按实际书籍/书签同步 `categories.book_count`、`tags.use_count`（seed 数据未维护冗余字段，导致分类计数恒为 0）。
