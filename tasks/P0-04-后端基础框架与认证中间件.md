# P0-04 后端基础框架与认证中间件

- **编号**：P0-04
- **任务名称**：后端基础框架与认证中间件
- **阶段**：P0 地基与数据
- **状态**：已完成

## 前置要求
- 材料：《功能需求.md》③ 技术栈、⑧ 非功能需求（安全/限流）
- 依赖子任务：P0-01（backend 工程）、P0-03（数据库 Schema）

## 任务内容
搭建 NestJS 模块化单体骨架与公共能力：
- **模块目录**：用户 / 书库 / 阅读 / 社区 / 会员 / 管理 六模块（预留平滑拆分）
- **统一响应格式**：标准 `{ code, message, data }` 结构
- **全局异常过滤器**：统一错误码与错误响应
- **结构化日志**：请求日志 + 异常日志
- **JWT 认证**：AccessToken + RefreshToken 双令牌、守卫（Guard）、Token 刷新
- **接口限流**：防刷风控基础（打卡/试用/兑换码场景预留）
- **Swagger 文档**：自动生成接口文档入口

## 结果
后续业务模块在统一规范上开发，无需重复造轮子；认证、限流、日志、文档开箱即用。

## 产物
- 公共模块代码（guards / interceptors / filters / middlewares）
- 六模块目录骨架
- Swagger 入口

## 验收点
- [x] 示例接口返回统一 `{ code, message, data }` 结构 — TransformInterceptor 全局注册
- [x] 无 Token 访问受保护接口返回 401 — JwtAuthGuard 全局注册 + @Public() 白名单
- [x] Token 过期后刷新接口可换新 Token — POST /api/auth/refresh 端点
- [x] 限流触发返回 429 — ThrottlerGuard 全局注册（默认 100/min，认证接口 10/min）
- [x] Swagger 文档可访问且接口可见 — /api/docs 入口 + Bearer 认证配置

## 实施清单
### 公共模块（common/）
| 文件 | 说明 |
| --- | --- |
| `guards/jwt-auth.guard.ts` | 全局 JWT 守卫，@Public() 装饰器白名单 |
| `filters/all-exceptions.filter.ts` | 全局异常过滤器，统一 `{ code, message, data }` 错误响应 |
| `interceptors/transform.interceptor.ts` | 全局响应拦截器，统一 `{ code: 0, message: 'success', data }` |
| `interceptors/logging.interceptor.ts` | 请求日志拦截器（方法/路径/状态码/耗时/IP/UA） |
| `decorators/public.decorator.ts` | @Public() 元数据装饰器 |
| `decorators/current-user.decorator.ts` | @CurrentUser() 参数装饰器 + JwtPayload 接口 |

### 认证模块（auth/）
| 文件 | 说明 |
| --- | --- |
| `auth.module.ts` | TypeOrm + JwtModule 异步注册 |
| `auth.controller.ts` | POST /register, /login, /refresh（均限流 10/min） |
| `auth.service.ts` | 注册/登录/刷新逻辑，dev 环境验证码固定 123456 |
| `dto/register.dto.ts` | 手机号正则校验 + 可选昵称 |
| `dto/login.dto.ts` | 手机号 + 验证码 |
| `dto/refresh.dto.ts` | refreshToken 必填 |

### 用户/管理模块
| 文件 | 说明 |
| --- | --- |
| `user/entities/user.entity.ts` | users 表实体（BIGINT 主键、软删除、审计字段） |
| `user/entities/user-auth.entity.ts` | user_auths 表实体（多认证方式） |
| `admin/entities/admin.entity.ts` | admins 表实体 |
| `user/user.controller.ts` | GET /user/profile（需认证） |
| `admin/admin.controller.ts` | POST /admin/login, GET /admin/profile |
| `admin/dto/admin-login.dto.ts` | 用户名 + 密码校验 |

### 六模块骨架
library / reading / community / membership 各含 controller/service/module，ping 端点 @Public()

### 根配置
| 文件 | 说明 |
| --- | --- |
| `config/index.ts` | 环境配置加载（DB/Redis/JWT/限流） |
| `app.module.ts` | ConfigModule + TypeOrm + Throttler + 六模块 + 全局守卫/过滤器/拦截器 |
| `main.ts` | ValidationPipe + CORS + Swagger Bearer + 全局前缀 /api |

## 待用户执行（沙箱限制）
1. `cd backend && npm install --legacy-peer-deps` — 安装新增依赖
2. `npm run build` — TypeScript 编译校验
3. 配置 MySQL 数据库后 `npm run start:dev` 启动服务
4. 访问 `http://localhost:3000/api/docs` 验证 Swagger
5. 访问 `http://localhost:3000/health` 验证健康检查
