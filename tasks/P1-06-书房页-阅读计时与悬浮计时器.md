# P1-06 书房页：阅读计时与悬浮计时器

- **编号**：P1-06
- **任务名称**：书房页：阅读计时与悬浮计时器
- **阶段**：P1 核心闭环
- **状态**：未开始

## 前置要求
- 材料：《功能需求.md》⑥ 页面5、④ 流程3（阅读记录）、⑤ 全局悬浮计时器规范、关键规则（手动计时）
- 依赖子任务：P1-05（在读书籍来源）

## 任务内容
实现核心差异化动作「开始阅读→计时→结束记录」：
- **书房页**（页面清单第 5 页）：在读书籍列表、开始/结束手动计时入口、今日时脉概览
- **计时流程**：开始计时 → 全局悬浮计时器持续计时（跨页面）→ 结束 → 填写起止页码与笔记摘抄 → 生成阅读场次（reading_sessions）
- **全局悬浮计时器**：底部固定胶囊面板，磨砂玻璃背景（rgba(255,255,255,0.9) + blur 12px），显示书缩略图、跳动时间（tabular-nums）、播放/暂停/停止切换（pine-deep 色）
- **后端**：reading_sessions 接口（创建/结束/查询），时长=结束-开始并扣除暂停

## 结果
核心闭环的「读中记录」环节跑通，计时数据沉淀为时脉报告的数据源。

## 产物
- 书房页
- 全局悬浮计时器组件（全局挂载）
- reading_sessions 后端接口

## 验收点
- [ ] 计时跨页面不中断（路由切换后悬浮计时器保持）
- [ ] 结束时填写页数/笔记生成场次
- [ ] 时长计算正确（暂停时段扣除）
- [ ] 页面刷新后可恢复进行中的计时
- [ ] 悬浮计时器视觉符合规范（磨砂胶囊、tabular-nums）
