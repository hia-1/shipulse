## API 一览
公开（`@Public`）：
- `GET /api/library/categories` — 分类树
- `GET /api/library/tags` — 标签列表
- `GET /api/library/books` — 列表（page/pageSize/keyword/categoryId/tagId/sort=default|new|hot|rating）
- `GET /api/library/books/isbn/:isbn` — 按 ISBN 查（仅已上架）
- `GET /api/library/books/:id` — 详情（含分类名 + tags）

管理侧（需 admin Bearer token）：
- `GET /api/library/admin/books` — 全部（含 pending/off_shelf）
- `POST /api/library/admin/books` — 建书
- `PUT /api/library/admin/books/:id` — 改书
- `PATCH /api/library/admin/books/:id/publish` / `off-shelf` — 上/下架
- `DELETE /api/library/admin/books/:id` — 软删除
- `GET /api/library/admin/isbn/:isbn` — ISBN 第三方拉取（降级返回 null）
- `POST/PUT/DELETE /api/library/admin/categories|tags` — 分类/标签管理
