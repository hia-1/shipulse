## 任务内容
搭建 monorepo 工程骨架，覆盖三端 + 后端 + 基础设施：
- `web-user`：Vue3 + Vite + Pinia + TailwindCSS（用户端 Web 站）
- `web-admin`：Vue3 + Vite + Element Plus（Web 管理端）
- `miniprogram`：原生微信小程序
- `backend`：Node.js + NestJS + TypeScript（模块化单体）
- 基础设施：Docker Compose 编排（应用 + MySQL 8.0 + Redis + Nginx）
- 环境配置：dev / test / prod 三环境隔离（.env 模板 + 环境变量约定）
- 文档：Swagger 挂载入口、各端启动说明

## 结果
四个端项目均可一键启动；`docker compose up` 后前后端互通；健康检查接口返回 200。
