- 后端：`backend/src/modules/notification/`（`notification.service.ts` / `notification.controller.ts` / `notification.module.ts`），复用既有 `notifications` 实体（未新建表）
  - 接口：`GET /notifications`（分类 + 分页）、`GET /notifications/unread-count`、`PATCH /notifications/:id/read`、`PATCH /notifications/read-all`
  - 触发接入：`review.service.ts`（书评点赞）、`comment.service.ts`（评论/回复，回复额外通知被回复者）、`post.service.ts`（动态点赞）

- 用户端：`web-user/src/api/notification.ts`、`stores/notification.ts`（60s 轮询未读）、`views/NotificationView.vue`（分类 Tab / 列表 / 已读 / 全部已读 / 加载更多）
- 入口：首页顶部导航「消息」带未读角标、个人中心功能入口带角标；路由 `/notifications`（需登录）；退出登录清空角标
