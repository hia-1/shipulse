## 交付清单

### 后端（backend/src/modules/search/）
| 文件 | 说明 |
| --- | --- |
| `search.module.ts` | 装配 LibraryModule + Redis provider；导出 SearchService/SuggestService |
| `search.service.ts` | 热搜词：Redis ZSET `search:hot` 自增 + 裁剪；**Redis 不可用时优雅降级到进程内存**（沿用 ISBN 降级哲学） |
| `suggest.service.ts` | 联想：书名/作者 LIKE 候选 + ISBN 精确命中（`findByIsbn`） |
| `search.controller.ts` | `@Public`：GET /suggest、GET /hot、POST /record（record 为 fire-and-forget） |
| `dto.ts` | `RecordSearchDto`、`SuggestQueryDto`（class-validator + Swagger） |
| `app.module.ts` | 注册 SearchModule |

Redis 注入点 `REDIS_CLIENT` 采用 `lazyConnect + retryStrategy:()=>null`：本地 Redis 未启动时不阻塞模块启动，SearchService 通过 `redis.status === 'ready'` 判断，自动降级内存，重启后热词不丢（内存）或持久（Redis）。

## API 一览（新增，公开）
- `GET /api/search/suggest?keyword=&limit=` → `{ books[], isbnHit|null }`
- `GET /api/search/hot?limit=10` → `[{ keyword, count }]`
- `POST /api/search/record` `{ keyword }` → `{ ok }`（热词自增，非阻塞）
