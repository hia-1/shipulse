## 前置要求
- 材料：《功能需求.md》② 账号体系、④ 流程1（注册登录）、⑥ 页面14
- 依赖子任务：P0-02（设计系统）、P0-04（认证中间件）

## 任务内容
实现 Web 用户端账号体系（页面清单第 14 页 登录/注册页）：
- **前端**：手机验证码登录表单、微信扫码登录（先预留接口/占位）、验证码防刷（倒计时/频次限制）
- **后端**：
  - 手机验证码发送（短信先 Mock，预留腾讯云短信接入点）
  - users / user_auths 注册登录接口
  - Token 发放与刷新
  - 游客可浏览策略（书城/书评/榜单可看，互动需登录）
- **状态管理**：Pinia 用户 store（登录态、用户信息、刷新逻辑）

## 结果
用户可注册、登录、登出，刷新页面保持登录态；游客可浏览但互动被拦截。

## 产物
- 登录/注册页
- auth 模块后端接口（发码/登录/注册/刷新/登出）
- Pinia 用户 store

- [ ] 验证码登录全流程通过（发码→输入→登录成功）
- [ ] Token 过期后自动刷新，无感续期

- [ ] 手机号唯一约束生效（重复注册报错）
- [ ] 刷新页面登录态保持
