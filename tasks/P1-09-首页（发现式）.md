## 任务内容

- **首页**：Banner 运营位（轮播）、每周好书、榜单入口、热门书评/动态流
- **榜单接口（Redis 热榜）**：热门（热度） / 新书（上架时间） / 高分（评分均分）
- Redis 不可用时优雅降级，保底可用

## 结果
游客无需登录即可发现好书的入口与氛围，找书不再书荒；榜单热度随书架/阅读冗余计数自然刷新。

## 产物
- 发现式首页 `views/HomeView.vue`（头部导航 + Banner 轮播 + 每周好书 + 榜单 Tab + 热门书评）
- 首页聚合 + 榜单接口（后端 `home` 模块）

## 后端接口
模块 `home`（前缀 `/home`）
- `GET /home/discover`（公开）首页聚合 `{ banners, weeklyBooks, rankEntries, hotReviews }`
- `GET /home/rank?type=hot|new|rating&limit=`（公开）榜单书籍列表（保持名次顺序、已过滤下架）

新增实体：`Banner`（banners）、`ColumnItem`（`columns`，每周好书/栏目）
新增服务：`RankService`（Redis 热榜）、`HomeService`（聚合）

## Redis 热榜
- `RankService` 以 Redis ZSET（key `rank:{type}`, score=热度/发布时间/均分）缓存榜单名次，TTL 5 分钟
- 命中即读缓存；未命中/Redis 不可用降级 MySQL 索引直查并尽力回写
- 注入模式复用 `search` 模块（REDIS_CLIENT，lazyConnect 失败不阻塞启动）
- 热度 = shelf_count + finished_count*2 + reading_count + review_count（冗余计数已由书架/阅读模块异步维护）
- 新书榜按 published_at、高分榜过滤 rating_count>0 后按 rating_avg
