# 管理端操作手册（P2-16 · 16-5）

> 面向运营/管理员。管理端 Web 地址：`https://<admin-domain>/`（本地开发：`http://localhost:5174`）

## 一、登录与权限

1. 打开管理端地址，进入登录页。
2. 输入**管理员用户名 + 密码**，点击登录。
   - 登录接口限流 10 次/分钟，连续失败请稍后再试。
   - 首次部署后请立即修改默认超管密码（默认 `admin/admin123`，生产环境使用默认口令会**拒绝启动**）。
3. 登录后按角色权限展示左侧菜单；无权访问的模块会自动跳回数据看板。

| 菜单 | 路径 | 所需权限 |
|------|------|----------|
| 数据看板 | `/dashboard` | `dashboard:view` |
| 用户管理 | `/users` | `user:read` |
| 书库管理 | `/books` | `book:*` |
| 内容审核与举报 | `/moderation` | `review:audit` |
| 运营管理 | `/operations` | `banner:*` |
| 会员订单与财务 | `/finance` | `order:*` |
| 系统设置 | `/settings` | `user:read` |

## 二、数据看板

- **统计概览**：用户数、书籍数、订单/营收、内容量等关键指标卡片。
- **趋势图**：近 N 天（默认 30 天）的注册/阅读/订单趋势，用于日常监控与运营复盘。
- 用途：快速掌握平台整体运行状况；异常波动时结合财务/审核模块下钻。

## 三、用户管理

1. 列表支持**关键词搜索**（昵称/手机号/用户 ID）与**状态筛选**。
2. 手机号默认**脱敏展示**（`138****0001`），不显示明文。
3. 常用操作：
   - **启用 / 禁用**：切换用户状态。
     - 禁用/注销会**立即失效**该用户已签发的所有令牌（强制下线）。
     - 「禁言（muted）」仅限制发布内容，用户仍可登录浏览。
   - **会员开关**：手动开通/取消会员。取消会员会同时清空到期时间。
     - 该接口限流 20 次/分钟，防止误触批量操作。
4. 注意事项：手动开通会员属**运营补偿**手段，正常购买请引导用户走会员购买流程。

## 四、书库管理

1. **书籍列表**：含「待上架 / 已上架 / 已下架」全量书目，支持分页与筛选。
2. **新增书籍**：
   - 支持**按 ISBN 拉取**第三方书目信息（失败会自动降级为手动录入）。
   - 必填：书名、作者、封面 URL 等；封面等图片地址必须是 http/https 合法链接。
3. **编辑 / 上下架**：
   - 上架后书籍才会出现在用户端书库与搜索中。
   - 下架书籍从用户端隐藏，但保留数据。
4. **删除**：软删除，可在必要时恢复。
5. 分类与标签：可新增/编辑/删除分类树与标签，用于用户端筛选。

## 五、内容审核与举报

1. **审核队列**：分「书评 / 动态 / 书单」三类，展示机器审核结论与风险分。
   - 机审通过的内容自动发布；命中敏感词转人工；命中违规词直接驳回。
2. **人工处置**：对待审内容执行「通过 / 驳回」。
   - 驳回时**需填写原因**，该原因会记录在审核日志并对用户可见。
   - 审核动作全部写入 `moderation_logs` 留痕，可追溯。
3. 注意事项：审核为**不可逆操作**，驳回后用户需重新提交，请谨慎判断。

## 六、运营管理

1. **Banner 管理**：
   - 新建/编辑 Banner：标题、图片 URL（http/https）、跳转类型与值、排序、上下线时间。
   - 跳转值仅允许站内路径、http(s) 链接或数字 ID，杜绝跳转到危险协议。
2. **专栏 / 每周好书**：
   - 按类型维护专栏内容，支持状态与关键词筛选。
   - 用于首页运营位的内容组织。

## 七、会员订单与财务

1. **订单概览**：订单量、营收等财务汇总。
2. **订单列表**：分页查看会员订单（用户、套餐、金额、状态、时间）。
3. **兑换码管理**：
   - **列表**：查看已生成的兑换码及使用状态。
   - **批量生成**：指定数量/套餐/有效期生成兑换码。
     - 接口限流 10 次/分钟，防止误触重复生成。
   - 兑换码为**一次性核销**，用户端核销接口限流 5 次/分钟以防爆破。
4. 注意事项：兑换码属于资产，导出/分发时注意保密，避免外泄。

## 八、系统设置

1. **管理员资料**：修改显示名称等资料。
2. **修改密码**：
   - 需输入原密码与新密码。
   - 修改成功后，该管理员已签发的令牌会失效，需重新登录。
   - 接口限流 5 次/分钟。

## 九、常见问题

| 问题 | 处理 |
|------|------|
| 登录提示「请求过于频繁」 | 触发限流，等待 1 分钟后重试 |
| 无法访问某菜单 | 当前角色无对应权限，联系超级管理员分配 |
| 审核驳回后用户反馈看不到原因 | 确认驳回时已填写原因，原因会随审核状态返回给用户 |
| 生成的兑换码用户核销失败 | 确认兑换码状态未使用、未过期，且套餐配置正确 |
| 用户被禁用后仍能访问 | 禁用/注销会立即失效令牌；如仍可访问请检查是否为「禁言」而非「禁用」 |

## 十、安全须知

- 管理端账号权限较大，请勿共用账号；离职人员及时回收。
- 生产环境建议在 nginx 层对管理端叠加 **IP 白名单**（配置见部署手册）。
- 所有敏感操作（审核、禁用、开通会员、生成兑换码）均有日志留痕。
